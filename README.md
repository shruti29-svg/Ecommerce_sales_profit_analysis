# E-Commerce Sales & Profit Analysis Dashboard

## 📊 Project Overview

The **E-Commerce Sales & Profit Analysis Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI. The project focuses on analyzing e-commerce sales performance, profitability, customer behavior, product performance, and order returns.

The dashboard transforms raw business data into meaningful visual insights, helping users understand sales trends, identify profitable business areas, analyze customer segments, and monitor overall business performance.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and profit performance.
- Track sales and profit trends over different years.
- Identify the contribution of different regions and sales representatives.
- Understand customer segmentation and geographical distribution.
- Analyze product categories and sub-categories.
- Monitor successful orders and returned orders.
- Provide interactive insights to support business decision-making.

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation.
- **DAX (Data Analysis Expressions)** – Measures and KPI calculations.
- **Excel** – Source data preparation.
- **Power BI Data Model** – Organizing tables and their relationships.

## 📁 Dataset & Data Model

The project uses a relational data model consisting of the following five tables:

| Table | Description |
|---|---|
| Orders | Contains order-level information, including Order ID, Order Date, Customer ID, Sales, Profit, and Region. |
| Customers | Contains customer details, including Customer Name, Country, State, City, Postal Code, and Segment. |
| Products | Contains product information, including Product ID, Product Name, Category, and Sub-Category. |
| People | Contains regional sales representative information. |
| Returns | Contains information about returned orders. |

These tables are used together to analyze sales, profitability, customer segments, product performance, regional performance, and returns.

## 📈 Dashboard Pages & Features

The Power BI report contains seven pages:

### 1. Sales Analysis Dashboard
- Overall sales performance.
- Sales contribution by region.
- Sales distribution by sales representative.
- Sales analysis by customer segment.
- Year-wise sales trends.
- State and product sub-category filters.

### 2. Customer Analysis
- Customer information and geographical details.
- Customer distribution by country, state, and city.
- Customer segmentation.
- Interactive city and state filters.

### 3. Product Analysis
- Product ID and product name details.
- Product category and sub-category analysis.
- Interactive product filters.

### 4. Profit & Sales Trend
- Year-wise sales trend analysis.
- Year-wise profit trend analysis.
- Comparison of business performance over time.
- Category and sub-category filters.

### 5. KPI Cards
- Order count.
- Successful order count.
- Successful order percentage.
- Return count.
- Return percentage.

### 6. Profit Analysis Dashboard
- Overall profit performance.
- Profit contribution by customer segment.
- City-wise and state-wise profit analysis.
- Profit contribution by sales representative.
- Year-wise profit trends.
- Sales and profit summary cards.

### 7. Security / Order Details
- Order ID.
- Product Name.
- Profit.
- Sales.
- Region.
- Order Date.

This page provides an order-level view of important business information.

## 📌 Key Business Metrics

The dashboard focuses on the following metrics:

- **Total Sales:** Sum of sales generated from orders.
- **Total Profit:** Sum of profit generated from orders.
- **Order Count:** Number of orders represented by the order count measure.
- **Successful Orders:** Count of successful orders.
- **Successful Order Percentage:** Percentage of successful orders.
- **Return Count:** Number of returned orders.
- **Return Percentage:** Percentage of returned orders.
